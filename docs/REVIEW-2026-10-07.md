std::vector<LogLine> TakeLast(const std::vector<LogLine>& Logs, std::size_t maxLines)
{
    if (Logs.size() <= maxLines)

    }

### REV2-CPP-FMT: Module Endpoint Formatting Duplication

**Files**: All 15 module containers in `cpp/modules/*/`

**Pattern** (duplicated ~15 times):
```cpp
// PostgreSQL, MariaDB, MongoDB, ClickHouse, RabbitMQ, Nats
const WslEndpoint endpoint = GetConnectEndpoint(DefaultPort);
return "Host=" + endpoint.Host + ";Port=" + std::to_string(endpoint.Port) 
       + ";Username=" + m_username + ";Password=" + m_password + ";Database=" + m_database;

// Redis, Qdrant, Elasticsearch, Keycloak, WireMock, Vault, MailPit
const WslEndpoint endpoint = GetConnectEndpoint(DefaultPort);
return endpoint.Host + ":" + std::to_string(endpoint.Port);
```

**Impact**: ~50+ lines of duplicate string formatting code  
**Fix**: Add helper methods to `WslModuleContainer`:
```cpp
protected:
    static std::string FormatEndpoint(const WslEndpoint& endpoint);
    static std::string FormatConnectionString(const WslEndpoint& endpoint,
                                            const std::string& username,
                                            const std::string& password,
                                            const std::string& database);
```
**Effort**: 2-3 hours  
**Priority**: HIGH (before 1.0)  

**Note**: C# already solved this — commit 79e2bea added `FormatHttpEndpoint` to `WslModuleContainer`.

## 📈 Adherence to AGENTS.md Guidelines

### ✅ Following Well
- Minimize public API surface
- Optimize for call site (fluent builders)
- Progressive disclosure
- Design consumer API first
- Minimize dependencies
- Expose capabilities, not implementation
